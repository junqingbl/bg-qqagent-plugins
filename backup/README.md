# 备份（backup）

给插件内核用的备份插件：**在云端把数据打包，留在服务器上**，需要的时候下载到电脑。

它不是同步盘——插件跑在服务器上，碰不到你电脑的硬盘。它做三件事：

1. 定时（或手动）把 `data/`、`diary/`、`plugins/` 打成一个 zip
2. 只保留最近 N 份，旧的自动删
3. 面板里列出所有备份，点一下就能下载

## 装

把 `backup/` 整个目录放进 `plugins/`，重启内核，面板会多一个「备份」页签。

适用于 `BG-QQagent` 插件内核（apiVersion 1）。

## 用

面板 →「备份」：

- **立即备份**：马上打一份
- **下载**：浏览器存到电脑（默认在「下载」文件夹）
- **删**：删掉某一份

默认每天 4 点自动打一份，留 7 份。可以在设置里改。

## 拿到电脑上

**手动**：面板点「下载」。

**半自动**（推荐）：服务器上永远有一个 `backups/latest.zip` 指向最新的一份，用一条 scp 就能拉：

```bash
scp root@你的服务器:/opt/qq-agent-bg/backups/latest.zip ./
```

Windows 上有个配套的 `备份到电脑.bat`，双击就跑完，按日期存到本地目录里。

## 配置

| 键 | 默认 | 说明 |
|:--|:--|:--|
| `dir` | `backups` | 备份放哪，相对程序根目录 |
| `sources` | `["data","diary","plugins"]` | 备份哪些目录，上面没有就跳过 |
| `keep` | `7` | 保留几份，1~60 |
| `autoDaily` | `true` | 每天自动备份 |
| `autoHour` | `4` | 几点打（0~23） |
| `format` | `zip` | `zip` 或 `tar.gz`；机器上没有 zip 时自动退到 tar.gz |

## 注意

- **备份里有 API key**：`data/config.json` 是明文，里面有模型密钥。备份别外发。
- 备份不含 `node_modules`，所以恢复后要重新 `npm install`。
- 恢复是手动动作：解压，把 `data/` `diary/` `plugins/` 放回程序目录，重启。插件故意不做「一键恢复」——那个点错了代价太大。
- `latest.zip` 是软链；某些解压工具不认软链，下载时会顺着读成实体文件，不影响。

## 结构

```
backups/
  luoluo-20261025-040000.zip
  luoluo-20261024-040000.zip
  latest.zip -> luoluo-20261025-040000.zip
```
