BG-QQagent · 插件

云端备份插件

每天定时把机器人的数据打包一次，掉链子的时候能找回来。装完面板里多一个「备份」页签，点一下就能下载到电脑。

能干什么

定时打包

默认每天 4 点，把 data、diary、plugins 打成一个 zip。

自动清旧

只留最近 7 份，超出的自动删，不占硬盘。

一键取回

面板里点下载，或者用脚本拉 latest.zip。

安装

把 backup/ 整个目录放进程序的插件目录，然后重启：

cp -r backup /path/to/qq-agent/plugins/
systemctl restart qq-agent-bg

面板顶栏会多出「备份」页签。

踩坑提醒：manifest.json 里只写 "ui": "ui.js" 是不够的，还必须写 uiTab。内核只从「已注册页签」里找界面文件，少这一行，点「配置」就会提示没有独立面板。

拿到电脑上

插件跑在服务器上，碰不到你电脑的硬盘，所以它只负责打包，取走要靠这一边。服务器上永远有一个 latest.zip 指向最新那份：

scp root@你的服务器:/opt/qq-agent-bg/backups/latest.zip ./

Windows 上配个计划任务每天拉一次，就不用惦记了。

配置

键默认说明
dirbackups备份放哪，相对程序根目录
sources["data","diary","plugins"]备份哪些目录，不存在的跳过
keep7留几份，1~60
autoDailytrue每天自动备份
autoHour4几点打（0~23）
formatzipzip 或 tar.gz，没有 zip 命令自动退到 tar.gz

下载

下载插件（zip） 去 GitHub 看源码

两个提醒
① 备份包里含 data/config.json，里面有模型 API key，别把备份发给别人。
② 备份不含 node_modules，恢复后要重新 npm install。恢复是手动动作——解压，把三个目录放回程序目录，重启。插件故意不做「一键恢复」，那个点错了代价太大。
